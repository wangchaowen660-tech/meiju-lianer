② 单词结构拼读

一个单词不是“看到字母就一个一个念”。

训练： 前面的辅音 → 中间的元音 → 后面的辅音 → 整体连接

例如： c → /æ/ → t → cat

③ 母句语块训练

不要把一句英语切成很多孤立单词。

学习： 语块 → 语块 → 整句

点击语块单独听

④ 母句语块自由转换

掌握一个母句之后， 替换里面的关键语块。

I want to go home.
I want to drink water.
I want to learn English.

⑤ 词族学习

零基础阶段，词族法不是先学词根词缀。

我们先学习： 押韵词族 + 高频单词 + 音块拼读 + 高频短句

一个共同的声音，带出一组单词。

例如： -at → bat → cat → fat → hat → mat → rat → sat

🔊 词族连续听音

先不要看中文。

让耳朵先听： bat → cat → fat → hat → mat → rat → sat

听完以后，再看中文确认意思。

03

04

🧱 多块音组合训练

有些单词不是简单的： 一个字母 + 一个字母。

我们开始训练： 音块 + 音块 → 单词
g + as → gas
sh + ip → ship
ch + at → chat
