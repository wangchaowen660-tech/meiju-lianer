🎧 Chaowen AI 英语主音拼读训练器 V1.3

IPA → 主音 → 两块音 → 词族 → 单词 → 母句 → 自由表达

🔊 本版本的核心： 哪里有英文，哪里就能点。
🧠 拼读思路： 前辅音 + 主音（元音）→ 第一块音 → 后辅音 → 整个单词。
例如： c + a → ca + t → cat

① IPA 48 音标

点击音标 → 听代表单词。
点击例词 → 听单词。
点击例句 → 听句子。

② 词族＋主音拼读

这是本版本最重要的升级。
先找到主音（元音），再让前后辅音围绕主音组合。

③ 单词拼读

从一个一个声音，进入两块音，再进入完整单词。

④ 母句语块

单词最终要进入句子。
点击单词听单词，点击句子空白位置听完整句。

⑤ 自由转换

一个句型，替换不同动作和对象。
